# Gadget catalogue product image sources

## Source and reuse terms

Product names and product-gallery photographs are from Adafruit Industries product pages and its public Products API. Adafruit API rules state that all content is copyright Adafruit, authorize use for an online store, and require that images not be hotlinked. Images are downloaded locally and credited below. Source terms: https://www.adafruit.com/products_api

The API provides the primary product image; the official product pages provide additional gallery views. Up to three distinct page gallery images are included for each product where available. Duplicate image files were excluded. Image files are stored unchanged.

Temu buttons all use the existing general affiliate URL, not product-specific links. The page tells customers that the Temu destination may not show the exact item pictured. No Temu product availability, price, or specification is claimed.
